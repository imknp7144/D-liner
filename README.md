# D-liner

**現在のバージョン: v1.0**

注意：V0.8からの更新の際は、venvの再構築が必要です。

注意：v0.9以前から更新して avif 画像を扱う場合は、Pillow 11.3 以上が必要です。
`setup_runtime_env.bat` を再実行してください（v1.0 では要求バージョンを
`Pillow>=11.3` に引き上げています）。導入済みのバージョンと AVIF 対応の可否は、
アプリの「ヘルプ > D-liner について」で確認できます。

AI画像生成物（イラスト・生成画像等）を対象とした、Windows向けのローカル完結型
画像管理・タグ付けアプリケーションです。

フォルダ単位での画像閲覧に加え、WD14 / Camie / JoyTag といったタガーモデルに
よる自動タグ付けをローカル環境（NPU / GPU / CPU）で実行し、タグによる検索・
整理を行えます。外部サーバーへ画像や生成物をアップロードすることはありません
（初回のみ、タグ付けモデル取得のために Hugging Face へアクセスします）。

> **プレリリース版です。** 動作環境や既知の制約について、導入前に
> [ユーザーマニュアル](docs/MANUAL.md) に必ず目を通してください。

## 主な特徴

- **SDI方式のプレビュー**: サムネイルをダブルクリックすると、画像ごとに独立
  したウィンドウが開きます（Linar最大の特徴を継承）
- **ローカルAIタグ付け**: WD14 / Camie / JoyTag から選択し、NPU（Intel）/
  GPU（DirectML）/ CPU いずれでも実行可能
- **タグ検索**: SQLiteベースの高速タグ検索（AND検索・INTERSECT戦略）
- **手動タグ・ロック機能**: AIの誤タグ修正や、LoRA学習用トリガーワードの
  手動追加に対応。画像単位でAI自動タグ付けの対象から明示的に除外可能
- **一括タグ操作 / LoRA用エクスポート**: 選択画像へのタグ一括追加・削除、
  画像＋キャプションのセットでのエクスポートに対応
- **コピー/類似検索モード**: タグパネルをコピーモードに切り替え、選択した
  タグをクリップボードへコピー、または組み合わせ検索が可能
- **メタデータビューア**: ComfyUI / A1111 で生成した画像に埋め込まれた
  プロンプト・ワークフローを専用ウィンドウで確認（[使い方](#メタデータビューアの使い方)）
- **GIF / アニメーションWebP の再生・AVIF 対応（v1.0）**: SDIウィンドウで
  アニメーションを再生。AVIF 画像もサムネイル・プレビュー・タグ付けの対象に
- **サムネイルキャッシュの管理（v1.0）**: サイズ上限（既定200MB）と終了時の
  自動整理、作成範囲の設定により、キャッシュの肥大化と起動の遅延を防止
- **バックグラウンド処理を妨げないUI**: フォルダスキャン・タグ付け・
  サムネイル生成はすべて非同期実行

## v1.0 の主な変更点

v0.9 から次の機能追加・改善・不具合修正を行いました。変更履歴の全体は
[CHANGELOG](CHANGELOG.md) を参照してください。

### 追加された機能

- **GIF / アニメーションWebP の再生**: SDIウィンドウで自動再生されます
  （サムネイル一覧は静止画のままです）。再生中の画像も、リネーム・移動・
  削除が可能です。ズーム・回転・反転も再生中に使えます
- **AVIF 画像への対応**: これまで一覧に表示されても「× Error」になっていた
  `.avif` ファイルが、サムネイル・プレビュー・SDI・タグ付け・解像度表示の
  すべてで扱えるようになりました（Pillow 11.3 以上が必要）
- **サムネイルキャッシュの管理**: 「ツール > キャッシュメンテナンス」から
  次を設定できます
  - サイズ上限（既定 200MB、下限 50MB）: 超えている場合、アプリ終了時に
    古いものから自動整理されます
  - 整理後の目標（既定 80%、50〜90%）: 上限のこの割合まで縮小します
  - 作成範囲（既定: DB登録フォルダのみ）: 「DB登録フォルダ＋お気に入り
    （配下を含む）」にも切り替えられます
  - 上限の95%に達していると、起動時にステータスバーで知らせます
- **詳細ペインに「追加日時」列**を追加（ファイル名／サイズ／追加日時／解像度／
  パスの順。未登録フォルダではファイルの更新日時を表示します）
- **ファイルのコピー／移動時の上書き確認に「残り全てに適用」**を追加
- **名前の変更（F2）を改善**: 入力欄で拡張子を除いた部分だけが選択された状態で
  開きます。SDIウィンドウでも `F2` でリネームできるようになりました
- **LoRAエクスポートの改善**: 出力先の親フォルダの履歴を保存するようにし、
  タグの「アンダースコア → スペース」置換オプション（anima系向け、既定ON。
  `score_` で始まるタグのみアンダースコアを維持）を追加
- **「ヘルプ > D-liner について」にバージョン情報を表示**: 動作中のPython・
  主要ライブラリのバージョン、AVIF / WebP の対応状況を確認・コピーできます

### 改善・不具合修正

- **起動が速くなりました**: 起動時にキャッシュDB全体を走査していたため、
  キャッシュが大きいほど起動が遅くなっていました（約50MBあたり1秒が目安）。
  起動時の確認を最小限にし、実測で 1〜2 ms になりました
- `F5`（更新）キーが反応しない不具合を修正（同じキーを2つの機能が重複して
  登録していたため、どちらも動かなくなっていました）
- 表示モードが「ウインドウサイズへ伸縮」「縦横固定して伸縮」のとき、SDIウィンドウを開いた
  最初の1枚で、画像の下部がタグパネルに隠れて見切れる不具合を修正
- フォルダ表示直後にホイール操作をすると、サムネイル先読みの完了時に一覧が
  先頭へ戻ってしまう不具合を修正
- ファイル削除時に一覧の位置が先頭へ戻る不具合を修正
- DB登録済みフォルダでF2リネームすると、DB上のファイルパスが更新されず、
  リネーム後に一覧の位置が先頭へ戻ってしまう不具合を修正
- 外部（エクスプローラー等）から監視中フォルダが削除された場合に、
  フォルダツリーでエラーダイアログが出る不具合の対象を拡大
  （権限エラー以外のOSエラーも同様に扱うようにしました）
- メタデータビューアの同期用チャンネルが起動できなかった場合の扱いを改善

## メタデータビューアの使い方

ComfyUI / A1111 で生成した画像に埋め込まれている生成情報（プロンプト・
ワークフロー等）を確認する、読み取り専用の補助ウィンドウです。D-liner本体とは
別プロセスで動作するため、ここでの操作がD-linerのデータベース・タグ情報に
影響することはありません。

### 開き方（2通り）

1. **サムネイル一覧で画像を右クリック →「メタデータビューアで開く」**
   画像（左）とメタデータ（右）を並べた通常表示で開きます。2回目以降は
   新しいウィンドウは増えず、既存のウィンドウの内容だけが切り替わります。
2. **SDIウィンドウで `V` キー**（または「ファイル > メタデータビューアで開く」）
   画像パネルを省いた省スペース表示（メタデータのみ）で開きます。SDIウィンドウで
   画像を切り替えると、メタデータビューアの表示も自動で追従します。
   複数のSDIウィンドウがあっても、メタデータビューアは常に1つだけ共有されます。

> サムネイル一覧にフォーカスがあるときの `V` は「SDIビューアで開く」動作です。
> メタデータビューアを開く `V` は、**SDIウィンドウにフォーカスがあるときだけ**
> 有効です。

### 画面の見かた

メタデータは種類ごとにカード（見出しつきの枠）に分けて表示されます。

| カードの見出し | 内容 |
|---|---|
| Positive / Base | ポジティブプロンプト（領域指定を使うワークフローでは共通のベース部分） |
| Regional A / B / C | 領域別プロンプト（Attention Couple 等） |
| Negative | ネガティブプロンプト |
| A1111 | A1111形式のパラメータ（プロンプト・Steps・Sampler・Seed等） |
| Note | 生成過程の注釈など、プロンプト以外のメモ（既定で非表示。上部のチェックで表示） |

カード内のテキストは選択してコピーできます（編集はできません）。

### 操作

| キー / 操作 | 動作 |
|---|---|
| `←` / `→` | 同じフォルダ内の前後の画像へ切り替え（通常表示ではマウスホイールでも可） |
| `Ctrl+O` | ファイル選択ダイアログから任意の画像を開く |
| ドラッグ&ドロップ | 画像ファイルをウィンドウへドロップして開く |
| `Esc` | ウィンドウを閉じる |

対応形式は PNG / JPEG / WebP / BMP / AVIF（アニメーションは GIF / WebP / APNG）です。

### 単体で起動する場合

D-liner を起動していなくても、D-liner と同じ venv で次のように実行できます。

```
cd <D-linerのフォルダ>
d_liner_runtime_env\Scripts\python.exe -m metahub_lite.viewer <画像ファイル>
```

### 復元できない場合

画像に埋め込まれたワークフローから実際のテキストを復元する仕組み上、次の場合は
正しい内容を表示できません（不具合ではなく原理的な制約です）。

- LLM / API 連携ノードなど、実行時に動的に生成されるキャプション
- `PresetText|pysssss` など、外部のプリセットファイルを参照するテキスト
- 一部の独自カスタムノード

詳細は [ユーザーマニュアル 6-11節](docs/MANUAL.md) を参照してください。

## 対応画像形式

JPEG / PNG / WebP（アニメーション含む）/ GIF（アニメーション含む）/ BMP /
TIFF / AVIF。AVIF の読み込みには Pillow 11.3 以上（標準のwheelにAVIF対応を
同梱）が必要です。

## 動作環境

| 項目 | 要件 |
|---|---|
| OS | Windows 10 / 11（64bit） |
| Python | 3.10 以上（システムPythonが別途必要。D-liner自体は専用venv内で動作） |
| Visual C++ 再頒布可能パッケージ | 2015-2022 (x64) が必要（onnxruntime系パッケージの依存関係） |
| NPU / GPU | 必須ではない。Intel NPUはOpenVINO経由、NVIDIA/AMD/Intel GPUはDirectML経由で高速化 |
| ネットワーク | タグ付けモデルの初回自動ダウンロード時のみ必要（Hugging Face） |

詳細は [ユーザーマニュアル 2章](docs/MANUAL.md) を参照してください。

## インストール

```
setup_runtime_env.bat
```

を実行すると、Pythonバージョン確認・NPU検出・専用venv構築・起動用ランチャー
生成までを自動で行います。NPU非搭載機やNVIDIA/AMD GPU搭載機など、自動検出を
上書きしたい場合は以下のように実行してください。

```
setup_runtime_env.bat --runtime directml
```

（`--runtime` の指定値: `auto`（既定） / `npu` / `directml` / `cpu`）

セットアップ完了後は `launch_d_liner.bat` から起動します。詳細な手順は
[ユーザーマニュアル 3〜4章](docs/MANUAL.md) を参照してください。

## 依存パッケージ

依存関係のインストールは `setup_runtime_env.py` が自動で行うため、手動での
`pip install` は不要です。以下は内容の参考情報です（実際のインストール対象は
`setup_runtime_env.py` 内の `COMMON_PACKAGES` を正としています）。

```
PyQt6>=6.7
numpy>=1.26
Pillow>=11.3
psutil
huggingface_hub
send2trash
piexif>=1.1.3
```

上記に加え、NPU / GPU / CPU いずれの構成かに応じて、以下のいずれか1つが
選択的にインストールされます（同一環境に共存できないため排他選択）。

| 系統 | 追加パッケージ |
|---|---|
| NPU（Intel OpenVINO） | `onnxruntime-openvino==1.24.1`, `openvino==2025.4.1` |
| GPU（DirectML） | `onnxruntime-directml==1.24.4` |
| CPU | `onnxruntime`（バージョン指定なし） |

なお `onnx` パッケージは、セットアップ時の動作確認（probe）専用の一時的な
依存であり、D-liner本体の実行には不要です。

## 既知の制約事項

- Intel NPU と NVIDIA/AMD GPU は同一環境で併用できません（onnxruntime-openvino
  と onnxruntime-directml が同一venv内で共存不可のため）
- 手動で削除したAI由来タグは、再タグ付けを行うと復活することがあります
  （ロック機能で除外可能）
- サムネイルキャッシュの作成範囲は既定で「DB登録フォルダのみ」です。
  未登録フォルダ・お気に入りのみのフォルダは、キャッシュが保存されないため
  表示のたびに画像を読み込み直します（キャッシュメンテナンスで範囲を変更可能）
- アニメーション（GIF / WebP）はSDIウィンドウでのみ再生されます。サムネイル一覧は
  最初のフレームを表示します（256MBを超えるファイルは再生せず静止画のままです）

その他の制約は [ユーザーマニュアル 9章](docs/MANUAL.md) にまとめています。
